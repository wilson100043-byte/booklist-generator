# 推薦書單生成及複本比對整合系統

純前端單檔 HTML 工具，使用 XLSX.js 在瀏覽器本機處理 Excel，不需要後端，也不需要 Node.js。

## 使用方式

1. 開啟 `index.html`。
2. 在入口選擇「系所比對」、「購買查重」、「格式轉換」，或「完整流程」。三項功能都可單獨使用。
3. 上傳出版社書單 Excel，選擇工作表；有購買查重時，再加入已購買書單。已購買檔只有一個工作表時會自動選取。
4. 把 Excel 欄位對應到書名、主題、ISBN 等資料。系所比對、格式轉換與完整流程必填書名與主題；購買查重仍只需要 ISBN。其餘展開「選填欄位」設定，箭頭右側預覽該欄位的前兩筆資料。
5. 系所比對需要關鍵字表。只需填寫學校名稱，按「下一步」直接顯示完整 AI 指令與三步操作說明，不會自動複製或顯示彈窗。按「選取全部指令」後手動複製，到 AI 開啟搜尋網路、貼上並送出；等 AI 整理好系所與關鍵字，再複製整份回覆，按「下一步：貼上 AI 的回覆」貼回結果。已有 CSV 可直接貼上或匯入，然後按「檢查關鍵字表」。格式為：

```csv
學校名稱,系所名稱,關鍵字
淡江大學,財務金融學系,財務金融;金融;投資;corporate finance
```

6. 格式轉換與完整流程另外設定學校代碼、主題代碼與 SDGs 判定方式。
7. 檢查摘要，產生並下載 Excel。左側步驟與「上一步」都能返回修改，本次輸入會保留；修改後需要重新產生輸出。

## 執行與技術

- 產品形式：瀏覽器內的 Excel 處理工具；`index.html` 為主入口，`書單工具_自訂欄位用途版.html` 為同功能的單檔入口。
- 前端：原生 HTML、CSS、JavaScript，負責灰階介面、分步操作、欄位對應與即時回饋；無 UI framework。
- 後端：不適用，所有書單處理都在瀏覽器執行。
- 資料儲存：頁面記憶體與使用者下載的 Excel；沒有資料庫，重新整理會清除本次操作。
- 主要套件：沿用 XLSX.js 0.18.5，用於讀取及產生 Excel。由既有 jsDelivr CDN 載入，不新增套件。
- 部署與執行：可直接開啟 HTML，或透過 GitHub Pages 部署為靜態網站。
- 本機啟動：在此目錄執行 `python3 -m http.server 4180 --bind 127.0.0.1`，開啟 `http://127.0.0.1:4180/`。
- 重要決策：保留既有系所比對、ISBN 查重、SDGs 與 Excel 輸出邏輯；以本機 UI 狀態管理步驟。視覺規則見 `DESIGN.md`。
- 已知限制：首次載入 XLSX.js 需要可連到 CDN；AI 需由使用者自行操作，且必須支援連網查找。指令會要求查證官方系所並避免編造，但工具不會自行查證外部 AI 回覆；CSV 格式檢查不代表系所清單完整或關鍵字內容正確，仍須人工確認。
- 後續擴充：可依真實使用回饋調整欄位分組；離線套件、儲存設定與自動 AI 串接尚未實作。

## 驗證

已使用專案原有版本的 XLSX.js 0.18.5，以合成書單走完四種模式，並逐格比對改版前後的工作表輸出；結果一致。另已檢查真實檔案下載、指令顯示與手動選取、CSV 貼上／匯入／重新檢查、必要欄位、空白工作表、舊輸出清除、瀏覽器返回、直接網址與 375／768／1024／1440px 版面。

可重跑的 UI 測試在 `tests/ui-smoke.cjs`。先啟動本機靜態伺服器，再於已有 Node.js、Playwright 與 Google Chrome 的開發環境執行 `node tests/ui-smoke.cjs`；可用 `TARGET_URL` 指定其他預覽網址。`XLSX_TEST_SCRIPT` 可指向既有的 XLSX.js 0.18.5 本機腳本，供測試攔截 CDN 請求，不改變正式頁面的載入方式。測試工具不屬於產品執行依賴，本次沒有安裝套件。

以上是功能與基本可用性驗證，尚未由真實使用者驗收，也不代表完成所有瀏覽器與完整無障礙稽核。

## 主要特色

- 不寫死 Wiley 或任何出版社欄位名稱。
- 出版社原始欄位不會被修改。
- 輸出 Excel 保留原始欄位與原始順序，只在最後新增結果欄位。
- 系所比對只使用使用者指定的書名、主題、子主題、內容簡介、目次欄位。
- 已購買查重使用指定 ISBN / 查重欄位，並先 normalize ISBN。
- 系統上傳格式是獨立功能，依使用者指定欄位直接產生。

## 輸出新增欄位

- 對應系所
- 命中關鍵字
- 系所標記狀態
- 是否已購買
- 購買比對值
- 購買比對來源
- 已購買日期
